# College Command Center

Application planning, research, and the working app for Fall 2027 entry.
Nine schools, applications targeted for submission by mid-November 2026.

**The app:** "The Callboard" — a guided workbench that shows the two or three
things that matter today, coaches the essays question-by-question, and exports
everything to Excel, PDF, or a single offline file.

---

## Working on this

The page that ships is **committed to the repo**, not built by the host. So the
one rule that matters:

```bash
# 1. edit the source
vim src/data.js          # tasks, schools, costs, contacts, glossary
vim src/app.css          # the visual design
vim src/essays.js        # essay coaching questions

# 2. rebuild  ← never skip this
python3 build.py

# 3. commit BOTH the source and the rebuilt page
git add -A && git commit -m "..."
```

`build.py` inlines everything in `src/` into one self-contained HTML file and
writes it to three places. If you edit `src/` and don't rebuild, the live site
keeps serving the old page and nothing visibly complains — so CI checks this on
every pull request and fails if the committed page doesn't match `src/`.

The build is reproducible: the same `src/` always produces a byte-identical
page. The `BUILD` stamp in the footer is a hash of the sources, so two people
seeing the same stamp are looking at genuinely the same page.

### Branches

`main` is the trunk and the source of truth. Work happens on a branch, goes
through a pull request, and merges back. Nothing is committed to `main`
directly.

## Layout

```
src/           Source. Edit here.
  index.html     page skeleton and static copy
  data.js        tasks, schools, money, contacts, glossary
  essays.js      essay coaching question sets
  app.js         rendering and state
  app.css        the visual design
  xlsx.js        Excel export

build.py       Inlines src/ into one self-contained page

index.html             ) all three are BUILD OUTPUT
site/index.html        ) identical, generated by build.py
app/callboard-offline.html )  do not hand-edit

docs/          Planning and decision documents
research/      Verified research findings, sourced and dated
```

**Known wart:** `index.html` and `site/index.html` are the same file committed
twice, because three separate Vercel projects deploy this repo with different
root directories. Collapsing to one Vercel project would let one of them go.

## Ground rules

**This repository stays private.** `research/` contains household financial
details and a minor's application profile. `.vercelignore` keeps those off the
public site; repository visibility is what keeps them off GitHub. Do not make
this repo public.

**Essays are hers.** This project produces brainstorming scaffolds, question
sets, outlines, reverse-outlines, and revision feedback. It does not produce
essay drafts. Several of these schools require applicants to attest that their
writing is their own.

**Nothing gets acted on unverified.** Every deadline, dollar figure, and prompt
carries a source and a date, or it's marked `UNVERIFIED — CONFIRM WITH SCHOOL`.
Gaps are labeled, never filled with plausible numbers.
